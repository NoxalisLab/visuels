A German web host was breached through the MCP server it built so customers' AI assistants could manage their sites.

56 customer projects compromised, 8 days undetected. Today the attackers are back: website down, SSH off.

Is your MCP endpoint audited? #MCP #AISecurity
---
Mittwald's timeline: first probe of the MCP flaw on Oct 21, during the PHP2Shell rush. Normal-looking test accounts from Oct 23, targeted exploit on Oct 27, detection on Nov 4.

Logs show seconds between steps, which Mittwald reads as AI tooling. No other proof shared yet.
---
If you expose an MCP server, treat it like a public API: least-privilege tokens per tool, no shell or file access by default, rate limits, and alerts on machine-speed sessions from new accounts.
